# 🎯 Tkinter Number Guessing Game

A simple interactive desktop game built using Python's `tkinter` library.

## 🚀 Features
- **Interactive GUI**: Dark-themed user interface built with standard Tkinter widgets.
- **Keyboard Shortcut Support**: Submit guesses by clicking the button or pressing the **Enter** key.
- **Attempt Counter**: Tracks the total number of attempts taken to guess the target number.
- **Input Validation**: Automatically handles empty inputs, non-integer characters, and invalid values gracefully.
- **Game State Controls**: Input controls automatically disable upon winning to prevent accidental inputs until a new game is started.

## 📋 Requirements
- **Python 3.x** (`tkinter` comes pre-installed with standard Python packages on Windows and macOS).
